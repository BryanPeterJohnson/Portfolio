# IT Solutions — Portfolio

Portfolio website: Websites, Mobile Apps & Custom Software.

## Host on GitHub Pages
1. Create a new public repository on GitHub (e.g. `portfolio`).
2. Upload `index.html` and the `assets` folder (keep the folder name the same).
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. After 1–2 minutes your site is live at `https://<your-username>.github.io/portfolio/`.
